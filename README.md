# Custom Event Product Section для Shopify

**Custom Event Product Section** — це гнучка кастомна секція для сторінки продукту Shopify, яка дозволяє збирати “праву колонку” картки товару з окремих блоків (через drag&drop у Customizer), з варіативним вибором (варіант-пікер кнопками) та формою для збору персональних даних для чекауту.

---

## Що робить секція

- Відображає зображення, назву, опис і ціну товару.
- Дозволяє змінювати порядок блоків (drag&drop).
- Виводить варіанти товару не списком, а кнопками (сучасний UX).
- Має налаштовувану форму для персональних даних, які зберігаються в замовленні (line_item properties).
- Всі ключові налаштування доступні у Customizer (Shopify Theme Editor).

---

## Доступні блоки

- **Product image** — головне зображення товару
- **Title** — назва товару
- **Description** — опис товару
- **Price** — ціна вибраного варіанту
- **Variant selector** — кастомний вибір варіантів (кнопки)
- **Checkout form** — форма збору персональних даних (можна приховати через налаштування блоку)

---

## Налаштування секції

В Customizer ти можеш:

- **Змінювати порядок блоків** — перетягуй їх у потрібному порядку (drag&drop)
- **Вмикати/вимикати форму користувача**  
  В блоці “Checkout form” є чекбокс **Show customer form**:
  - **Включено**: показуються поля для імені, email тощо
  - **Вимкнено**: відображається тільки кнопка “Buy & Checkout”, форма не показується

---

## Як користуватися

1. **Додай секцію** на сторінку продукту (Product page template)
2. **Відкоригуй порядок блоків** через drag&drop у Customizer
3. **Налаштуй блок “Checkout form”:**
    - Включи або вимкни форму персональних даних (Show customer form)
4. **Перевір відображення:**  
    Обирай варіанти товару, переконайся, що ціна змінюється, всі поля працюють і потрапляють у замовлення
5. **Для тестової покупки** — використовуй Bogus Gateway (номер картки `1`)

---

## Лайфхаки і нюанси

- Варіант-пікер працює для будь-якої кількості опцій (будь-який продукт з варіантами)
- Персональні дані додаються до замовлення у властивостях товару (Shopify Admin → Order)
- Якщо форма вимкнена, в кошик додається лише товар без даних користувача
- Секція повністю адаптивна і не конфліктує з іншими елементами сторінки продукту
